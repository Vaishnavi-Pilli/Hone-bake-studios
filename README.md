
# Honey Bake Studio — Multi-page Website

## Files
- index.html — Home
- about.html — About the bakery
- cakes.html — Cakes, brownies and cupcakes
- gallery.html — Image gallery
- contact.html — Contact information
- styles.css — Shared styles and animations
- script.js — Navigation and scroll effects

## Run locally
1. Put all files in the same folder.
2. Open index.html in a browser.

Optional: run a local server:

    python -m http.server 8000

Then open http://localhost:8000.

## Before publishing
- The photographs are demo images from Unsplash, not verified photos of Honey Bake Studio products.
- Replace demo images with approved bakery photographs.
- Confirm all contact details with the owner.
- No prices, customer reviews or delivery claims have been invented.
- The 24-hour advance-booking notice is included as provided.
- Google Fonts and image links need an internet connection.
